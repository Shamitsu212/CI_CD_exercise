# ⚙️ GitHub Actions CI/CD Demo

ENG: A demonstration project showing how to set up a CI/CD pipeline using GitHub Actions. The workflow automatically installs dependencies, builds a Vite + React application, and deploys it to GitHub Pages after every push to the `main` branch.

RU: Демонстрационный проект, показывающий настройку CI/CD с использованием GitHub Actions. Workflow автоматически устанавливает зависимости, собирает приложение на React + Vite и публикует его на GitHub Pages после каждого пуша в ветку `main`.
